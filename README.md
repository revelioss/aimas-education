# Aimas Education — сайт

Статический сайт (HTML, CSS, JS). Главная страница — о бренде, каталоге и услуге «книга на заказ». Отдельная страница товара — книга «Animals and Friendship».

## Страницы

- `index.html` — главная
- `books/animals-and-friendship/index.html` — страница книги

Откройте именно файлы `index.html` (относительные ссылки рассчитаны на это). Можно также запустить:

```bash
cd book_site
python3 -m http.server 8765
```

## Настройки

В начале `js/main.js`:

- `price` — цена готовой книги (сейчас «9 500 ₸»)
- `customPrice` — цена книги на заказ (сейчас «9 500 ₸»)
- `instagramProfile` / `instagramHandle` — @aimas.education
- `whatsapp` — номер WhatsApp для заявок (`77755231543`, wa.me без + и пробелов)
